### 判定の読み方

| 表記 | 意味 |
|---|---|
| 策定済 | 計画本体または策定を明示するページを検索結果で確認 |
| 策定中 | 策定支援業務の公募等、策定作業中であることを確認 |
| なし | 自治体側の記述から「策定していない」と読み取れる |
| 確認できず | Web検索の範囲では公開情報を確認できなかった（＝未策定とは限らない） |

「確認できず」は **未策定の可能性が高い** が確定ではない。
特に小規模町村は計画をHTMLではなくPDFのみで掲載しており検索インデックスに乗りにくい。

## 3. 営業・提案上の着眼点

1. **区域施策編が未策定の66自治体**が潜在ニーズ。特に事務事業編は持つが区域施策編がない
   自治体（平内町・田子町・美浦村・河内町・仙北市・美郷町・羽後町・猪苗代町・柳津町・塙町・
   新地町・三川町・涌谷町 ほか）は、次の改定タイミングで区域施策編へ拡張する動機がある。
2. **舟形町は R7年度に区域施策編を策定中**（履行期限 R8.1.16）。同種案件の直近事例として参照可。
3. **藤崎町は区域施策編・事務事業編・地域気候変動適応計画を一体策定**（2025年度策定、
   計画期間2026-2030）。小規模町村向けの一体型モデルとして提案材料になる。
4. ゼロカーボンシティ宣言済で計画が未整備の自治体（柳津町など）は優先度が高い。
5. 再エネ・脱炭素の個別施策が先行している自治体
   （国見町の再エネ調和条例、八峰町の再エネ建設ガイドライン、九戸村の再エネ導入計画、
   鮫川村のバイオマスの里構想、大衡村・小野町の地域新エネルギービジョン、
   風間浦村のブルーカーボン重点調査、七ヶ宿町の営農型太陽光）は、
   上位計画としての区域施策編が欠けている状態。

## 4. 精度を上げるための次アクション

1. 環境省サイト（`www.env.go.jp` / `policies.env.go.jp`）を egress 許可リストに追加する。
   自治体別ページ70件を参照すれば「確認できず」66件が確定値になる。
2. あるいは環境省「地域脱炭素の推進に関する状況調査」結果のExcel（令和6年10月1日時点）を
   別途入手し、団体コードで突合する。
3. 各県の環境部局が公表する市町村別一覧
   （例：福島県の施行状況調査回答一覧、岩手県「いわて脱炭素経営カルテ」）も併用する。
