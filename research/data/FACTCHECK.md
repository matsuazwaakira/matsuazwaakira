# ファクトチェック手順（2026-09-30, 令和8年度）

目的: research/data/*.json のうち「終期がR9年度（t_end/e_end=9）」とした計画について、主張が正しいかを独立に検証する。営業判断に使うため、誤りを見つけることが最優先。

各対象について:
1. WebSearch（ToolSearch "select:WebSearch" で読み込み）で、計画書・計画ページ・議会/協議会資料など一次情報に近いものを探し、「計画期間」の記述（例「令和5年度から令和9年度まで」）を検索結果本文で確認する。既存JSONのURLを鵜呑みにせず、別経路で確認すること。自治体サイトへの WebFetch はブロックされがち（1〜2回試して無理ならやめる）。
2. あわせて、次期計画の策定に既に着手しているか（策定支援業務のプロポーザル/入札、協議会での次期計画審議、アンケート、パブコメ）を確認する。
3. 判定:
   - verdict: 「正しい」（R9年度終了を本文で確認）/「誤り」（別の期間を確認）/「確認できず」
   - 1回の検索要約だけを根拠に「正しい」としない。本文の記述が見つからなければ「確認できず」。
4. 出力: 下記スキーマのJSON配列を指定ファイルに保存（ensure_ascii=False, indent=1）し、検証後そのファイルだけをコミットしてブランチ claude/epic-davinci-sky0yc に push（拒否されたら git pull --rebase してから再push、最大4回）。
   {"pref","name","plan":"交通|環境","claimed":"既存JSONの期間","verdict":"正しい|誤り|確認できず","found_period":"確認できた期間 or null","evidence_url":"根拠URL（検索結果に出たもののみ）","evidence_quote":"根拠の短い引用","next_plan":"次期計画の着手状況（着手済の場合は日付・URL）or 確認できず","note":""}
5. 検索上限は1セッション200回（サブエージェント合算）。1件あたり4〜5回を目安に配分。
6. 最後に、誤り・確認できずの件と、次期計画に着手済みだった件を短く報告。
